# AI研修ビジネス 実行プラン：メニュー設計・売り込み構成・初動90日

前提とする戦略（元記事の骨子）:

- 研修は単発のフロー収益ではなく、**報酬をもらいながらやる業務リサーチ**であり、伴走・顧問・業界特化サービスというストック収益への入口。
- 人材開発支援助成金（事業展開等リスキリング支援コース）は **2027年3月31日まで**。中小企業は経費助成 最大75% ＋ 賃金助成 1人1時間1,000円。
- 助成対象は **OFF-JTで訓練時間10時間以上**。よって売り物のメニューは最初から10時間以上で設計する。
- 申請は顧客企業側が行う。講師側は「制度を正確に案内できる」だけで研修会社との比較優位になる。計画届は訓練開始1か月前までに労働局へ。

---

## 1. 研修メニューのアイデア出し

### 1-1. 設計原則

1. **10時間以上・OFF-JT** を全メニューの基本形にする（助成金要件）。半日セミナーは「フロント商品（無償/低額）」に位置づけ、助成金営業には使わない。
2. **講義3割・演習7割**。顧客が買うのは知識ではなく再現性。演習題材は必ず「受講企業の実業務データ・実文書」を持ち込ませる。
3. すべての演習に**削減時間の計測**を組み込む（Before/After分）。研修の成果報告書が次の提案書の根拠になる。
4. カリキュラムの中に**業務ヒアリングが自然に発生する構造**を入れる（後述のワークシート）。STEP5「調査としての研修」を仕組みで担保する。

### 1-2. 基幹商品：汎用「業務AI活用ブートキャンプ」（12時間 / 2日 or 半日×4回）

最初の数件はこれで回し、受講者の反応から特化メニューを抽出する。

| 回 | 時間 | 内容 | 狙い（表向き / 裏の調査項目） |
|---|---|---|---|
| 1 | 3h | AIの現在地とリスク（情報漏えい・ハルシネーション・社内ルール）＋ 基本操作演習 | 心理的抵抗の除去 / 「データが汚い」「禁止されている」等の発言部署を記録 |
| 2 | 3h | 文書業務の効率化：メール・議事録・報告書・稟議書を自前文書で書き換える演習 | 即効の成功体験 / どの文書業務に時間が溶けているかの実態 |
| 3 | 3h | 部署別ワーク：自部署の業務を棚卸しし、AI適用候補を選んで実際に試す | 業務棚卸しワークシートの回収 / Excel手作業・属人業務の一覧が手に入る |
| 4 | 3h | 成果発表会＋削減時間の集計＋「次の90日プラン」を各部署が宣言 | 経営層を同席させる / 実質の意思決定者と温度の高い部署の特定 |

- **成果物（顧客向け）**: 削減時間サマリー、部署別AI活用プラン、社内利用ガイドライン雛形
- **成果物（自分向け）**: 業務棚卸しシート全数、質問ログ、キーパーソンマップ → そのまま最終日の伴走提案書の素材

価格の目安: 1人あたり20万円 ×10名 = 200万円規模で設計し、「助成金適用で実質約50万円＋賃金助成」を提示できる形にする（金額は自社の実績・地域相場で調整）。

### 1-3. 特化メニューの種（反応を見て絞り込む候補）

作り込んでから売るのではなく、汎用研修の反応記録から**指名される領域**を選ぶ。候補リスト:

**業種特化**
- 製造業: 見積・図面問い合わせ対応、検査報告書の自動下書き、技能伝承ドキュメント化
- 建設業: 施工計画書・安全書類の作成支援、写真台帳の整理、積算の下調べ
- 士業（税理士・社労士・行政書士）: 顧問先向け回答ドラフト、条文・通達リサーチ、記帳補助
- 不動産: 物件紹介文・重説ドラフト、問い合わせ一次対応、周辺調査レポート
- 医療・介護: 記録業務（ケア記録・看護サマリー）の下書き、シフト調整補助、家族向け説明文
- 小売・EC: 商品説明文の量産、レビュー分析、問い合わせテンプレート生成
- 運送・物流: 配車日報の自動化、荷主向け報告書、求人票作成

**職種特化（業種横断）**
- 営業部門: 提案書・見積の高速化、商談議事録→次アクション抽出、顧客リストの下調べ
- 経理・総務: 仕訳の下調べ、規程類の改定ドラフト、問い合わせFAQ化
- 人事・採用: 求人票・スカウト文面、面接評価の構造化、研修資料の内製
- カスタマーサポート: 回答ドラフト生成、VOC分析、ナレッジベース構築
- 経営者向け（少人数・高単価）: AI経営判断合宿——自社のどの業務から入れるかを2日で決める

**テーマ特化**
- 「AI社内ルール策定ワークショップ」: ガイドラインを一緒に作る研修。顧問契約への接続が最も自然
- 「Excel手作業撲滅」: どの会社にも刺さる普遍テーマ。業務リサーチ効率が最も高い
- 「AIで作る採用・広報コンテンツ」: 成果が目に見えやすく事例化しやすい

選定基準: ①汎用研修で質問が集中した領域 ②複数社で同じ詰まりが出た領域（=10社共通なら事業になる） ③自分のSTEP1実績と地続きの領域。

## 2. 企業への売り込み構成（提案の型）

### 2-1. 商談・提案書の流れ（この順番で話す）

1. **自分の数字**（30秒）: 「見積作成が3時間→10分になった」等、STEP1で作った実績を最初に。肩書きや資格ではなく数字で信用を作る。
2. **相手の痛み仮説**（2分）: 業種特化の困りごとを2〜3個言い当てる。「御社もおそらく◯◯に時間が溶けています」。事前に同業他社での記録があれば最強。
3. **研修の中身**（3分): カリキュラムは詳細を語らず、「講義3割・演習7割」「御社の実データで演習」「削減時間を数字で報告」の3点だけ。
4. **お金の話＝助成金**（5分・ここが山場）:
   - 「200万円の研修ですが、人材開発支援助成金で経費の75%が戻り、実質負担は約50万円。加えて訓練時間中の賃金助成が1人1時間1,000円付きます」
   - 「申請は御社側で行いますが、必要書類・スケジュールはすべてこちらで案内します。計画届は開始1か月前までなので、逆算すると◯月に着手が必要です」
   - **期限訴求**: 「この制度は2027年3月31日で終了します」——先延ばしの最大の敵に効く。
5. **出口の予告**（1分）: 「最終日に、研修中に見えた御社の業務課題を整理してご報告します」。伴走提案の布石を最初から打っておく。

### 2-2. 提案書テンプレートの構成

1. 貴社の課題仮説（業種の一般論＋ヒアリング内容）
2. 研修概要（目的・対象・時間数≥10h・スケジュール）
3. カリキュラム表（上記1-2の表形式）
4. 成果の測り方（削減時間レポートのサンプルを見せる）
5. 費用と助成金シミュレーション（総額→助成額→実質負担→賃金助成、の4段表記）
6. 助成金申請スケジュール（計画届1か月前ルールを含む逆算カレンダー）
7. 研修後のご支援メニュー（伴走・顧問の存在だけ予告。金額は最終日に）
8. 講師実績（自分の削減数字＋過去受講企業の声）

### 2-3. 決裁を速くする一言集

- 「払うのは御社の財布の4分の1、残りは国の財布です」
- 「50万円の稟議と200万円の稟議では通る速さが違います。今回は50万円の稟議です」
- 「制度終了は2027年3月。来期に回すと総額負担が4倍に戻ります」
- 注意: 助成金の**受給を保証しない**こと。「申請主体は御社であり、支給決定は労働局の審査によります」を提案書に明記（トラブル防止＋誠実さの演出）。

## 3. 初動でやること（90日プラン）

### Day 0–14: 自分の実績づくり（STEP1）

- [ ] 自分の業務（または身近な1業務）にAIを入れ、**Before/Afterの時間を計測**して3つ数字を作る
  - 例:「見積書 3時間→10分」「議事録 60分→5分」「問い合わせ下書き 週5時間削減」
- [ ] その過程を1枚のスライド＋X/noteの記事にする（発信の初弾＆提案書の実績ページ）
- [ ] 助成金の一次情報を読み込む: 厚労省「人材開発支援助成金（事業展開等リスキリング支援コース）」の支給要領・様式。**「DX化に伴う訓練」類型なら認定支援機関の確認は不要**、という点まで自分の言葉で説明できるように
- [ ] 汎用12時間カリキュラム（上記1-2）と提案書テンプレを作る。完成度6割でよい

### Day 15–45: 初期案件の獲得（STEP2）

- [ ] **無償研修を1〜2社**: 身近な経営者に「モニターとして無償。対価は実名の事例掲載と2社の紹介」という条件で実施
- [ ] 既存人脈への案内: 前職取引先・商工会議所・地元経営者会に「実績スライド＋助成金1枚資料」を持って回る。売り込みではなく「こういう制度があるのをご存知ですか」から入る
- [ ] 発信を週2本: 削減事例・助成金解説・受講者の変化。広告費ゼロの信用形成
- [ ] 無償研修でも**業務棚卸しシート・質問ログ・キーパーソンメモ**は本番同様に取る（調査資産の第1号）

### Day 46–90: 有償化と型の抽出（STEP3–6）

- [ ] 紹介経由で有償案件を2〜3社受注。助成金前提で10時間以上のメニューを提案
- [ ] 案件ごとに逆算スケジュール管理: 受注→計画届（開始1か月前）→実施→最終日の伴走提案
- [ ] 反応記録の週次レビュー: どのパート・どの業務の話で前のめりになったかを記録し、**特化メニュー第1号**を決める
- [ ] 最終日の型を必ず実行: 「研修中の質問を整理すると御社の詰まりは◯◯に集中しています。ここをAIで直すところまで伴走しましょうか」→ 月額伴走 or 顧問の見積を最終日から1週間以内に提出
- [ ] 3か月時点のKPI: 実施4社以上 / 削減時間の実測データ3社分 / 伴走・顧問の継続契約1件以上 / 特化領域の決定

### 常時やること（2027年4月を見据えて）

- 顧客ごとに「業務フロー・詰まり一覧・意思決定者マップ」をNotion等で資産化。**これが助成金終了後に残る事業の本体**
- 複数社で同じ詰まりを見つけたらメモを昇格させる: 1社の困りごと=案件、10社共通の困りごと=事業（業界特化サービス化の候補）
- 売上構成のモニタリング: フロー（研修）とストック（伴走・顧問）の比率を毎月確認し、2026年末までにストック比率50%を目標にする

## 4. リスクと注意点

- **助成金の不確実性**: 支給決定は労働局審査。要件変更もあり得るため、提案書には必ず免責を明記し、最新の支給要領を都度確認する。申請代行は社労士の独占業務のため、講師は「案内」に徹する。
- **単価下落**: 助成金バブルで参入者が増え、汎用研修は価格競争になる。だからこそ特化と最終日の伴走提案が生命線。
- **顧客情報の扱い**: 研修で得た業務情報は機密。秘密保持契約を結んだうえで、事例化は必ず許諾を取る。調査資産の運用こそ信頼を失いやすいポイント。
- **教えすぎ問題**: 研修で全部内製化されると伴走が売れない、と考えるのは逆。底上げされた社員がいる会社ほど伴走契約は続く。出し惜しみせず教えるのが正解。
