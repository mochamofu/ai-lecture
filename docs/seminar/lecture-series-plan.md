### Phase 1：初回開催の獲得（今月）

1. **川崎商工会議所に入会**し、事務局へセミナー企画書（1枚）を持ち込む。タイトルは「聞いて帰らない。作って帰る。」＋助成金サブコピー
2. 持ち込み時の一言：「**毎月テーマを変えて連載できます**」——単発講師の売り込みより、事務局の年間企画の穴を埋める提案の方が通る。第2部のシリーズ表を見せる
3. 反応が鈍ければ法人会・異業種交流会で1回実績を作って再訪
4. 並行して動画版を収録し、保存版コンテンツとして概要欄整備（資料DL・LINE・厚労省リンク・タイムスタンプ）

### Phase 2：第1講の実施 → シリーズ起動（1〜3か月目）

1. 第1講（入門編）を実施。**アンケートQ2を「次に聞きたいテーマ投票」に差し替える**（第2部のテーマ一覧から3つ選ばせる）
2. 最終盤で次回予告：「来月は『求人を出しても来ない会社のAI採用講座』をやります」——リピーターの種まき
3. 個別相談（LINE経由）→ ワーク3の続き → 10時間研修の提案 → 助成金逆算
4. 投票結果で第2講のテーマを確定し、制作（フォーマットは第1講の型を流用するので制作コストは初回の1/3以下）

### Phase 3：定例化と資産化（3〜6か月目）

- 月1回の連載枠として定着させる。**「今月の講座」がSNS・動画の月次コンテンツ供給源**になる（発信ネタ切れが構造的に起きない）
- 各講のワーク・机間巡視で見えた業種別の悩みを記録 → 10社共通の悩みが見つかったら業界特化サービス（事業）に昇格
- 講座受講企業への研修・伴走契約を積み、2027年3月の助成金終了までにストック収益（伴走・顧問）比率50%へ

## 第2部：講座シリーズ・カタログ「作って帰るAI経営講座」全10講

### シリーズ設計の原則（全講共通フォーマット）

- **1講 = 1つの経営の痛み**。AIの機能ではなく悩みでタイトルを付ける（「画像認識講座」ではなく「FAXの転記をなくす講座」）
- 全講とも第1講と同じ型：**約束3つ → ワーク中心（スマホのみ・逆質問法ベース）→ 魅せデモ1〜2本 → 持ち帰り成果物 → 個別相談へ**。この型自体がブランドになる
- どの講から参加しても成立する（連続受講は前提にしない）。ただし冒頭5分の「社名を入れないルール」と逆質問法の説明は毎回入れる
- 各講の最後に次回予告＋テーマ投票。**カリキュラムは講師が決めるのではなく、会場の投票と質問から抽出する**（=市場調査）

### カタログ（第1講は既存。第2講以降は優先順に）

| # | 講座名（悩みベース） | 対象の痛み | 持ち帰る成果物3つ | 魅せデモ |
|---|---|---|---|---|
| 1 | **聞いて帰らない。作って帰る。**（既存・入門） | 何から始めればいいか分からない | 自社の辛口診断書／値上げ文or求人票／最初の1業務 | FAX表化・2分社内AI |
| 2 | **求人を出しても来ない会社のAI採用講座** | 応募ゼロ・ミスマッチ・面接が我流 | 刺さる求人票／面接質問シート／スカウト返信文 | 競合求人の比較分析 |
| 3 | **値上げが言い出せない会社のお金の講座** | 価格転嫁できない・銀行に説明できない | 値上げ通知文／粗利シミュレーション表／銀行想定問答 | 決算数字→銀行員役AIの詰め問答 |
| 4 | **ベテランが辞める前に。技術承継のAI講座** | 職人の頭の中が会社に残っていない | 作業手順書1本／取材プロンプト集／承継計画メモ | 写真1枚→作業手順書、やさしい日本語＋外国語版 |
| 5 | **売り込みが苦手な会社のAI販促講座** | チラシ・SNS・口コミ返信が回らない | 商品紹介文10案／口コミ返信テンプレ／月間投稿カレンダー | Googleマップ口コミ全件→改善レポート |
| 6 | **Excelと紙の山を片付けるAI事務講座** | 転記・名寄せ・集計に人が張り付いている | 名寄せ済みリスト／FAQ集／転記自動化の手順 | 汚い顧客リスト一発整形 |
| 7 | **クレームに強くなるAI顧客対応講座** | 難しい客への返信で消耗している | お詫び文テンプレ／対応方針1枚／想定問答集 | お客様役AIとの予行演習ライブ |
| 8 | **社長の右腕をつくるAI顧問講座** | 相談相手がいない・計画が書けない | 自社専用AI（カスタム指示）／事業計画たたき台／補助金対象診断 | 公募要領PDF→自社が対象か即診断 |
| 9 | **社員に広げる。AI導入ルールと研修設計講座** | 個人では使えたが会社に広がらない | 社内ルール完成版／展開ロードマップ／助成金逆算表 | 就業規則AI（深掘り版） |
| 10 | **業界特化スピンオフ**（建設の安全書類／飲食の販促／介護の記録 等） | 各業界の固有業務 | 業界ごとに設計 | 業界ごとに設計 |

**優先順の根拠**：第2講（採用）と第3講（お金）は全業種共通で切実度が最も高く、第1講のワーク2（A/B選択）でどちらの需要が多いか実測できる。第4講（承継）は川崎の製造業に最も深く刺さる地域特化のエース。5〜7講は業種の幅を広げ、8〜9講は個別相談・研修への接続が最も強い「出口用」の講。

## 第3部：第2講の詳細設計（次に作る実物）

### 講座名：求人を出しても来ない会社のAI採用講座 〜90分で求人票を書き直す〜

**対象の痛み**：求人を出して3か月応募ゼロ。ハローワークの文面を10年使い回している。面接で何を聞けばいいか我流。若手に「アットホームな職場」が響かないことに薄々気づいている。

**本日の約束（3つ作って帰る）**
1. **来てほしい1人に刺さる求人票**（現状の求人票のビフォーアフター）
2. **自社専用の面接質問シート**（聞いてはいけない質問の回避込み）
3. **応募者への返信文テンプレ**（即レスの型。応募辞退の最大原因は返信の遅さ）

**タイムテーブル（90分）**

| 時間 | 内容 | 型 |
|---|---|---|
| 0-5分 | 約束＋ルール（社名NG・置き換え） | 共通導入 |
| 5-15分 | ワーク1「AI求職者に自社の求人票を読ませる」——今の求人票（またはよくある文面）を貼り、「あなたは28歳の転職希望者です。この求人に応募したくない理由を遠慮なく」 | 辛口診断の採用版。「アットホーム」が斬られる瞬間が掴み |
| 15-25分 | なぜ刺さらないか：「誰でも歓迎」は「誰にも刺さらない」。ペルソナを1人に絞る考え方 | 講義（短く） |
| 25-45分 | ワーク2「逆質問法で求人票を書き直す」——採用コンサル役AIが質問→話し言葉で答える→完成 | 本編。第1講の逆質問法の深掘り実践 |
| 45-52分 | 魅せデモ「競合求人の丸裸分析」——同エリア同職種の求人文面を貼り「求職者目線で比較。うちが勝てる訴求点は？」 | コンサル成果物風。個別相談への釣り針 |
| 52-67分 | ワーク3「面接質問シートを作る」——面接官役AIに「うちの◯◯職の面接質問を10個。NG質問（家族構成等）も教えて」 | 法的な地雷回避が入るので満足度が高い |
| 67-77分 | 応募者対応の型：返信は24時間以内・返信文テンプレを逆質問法で1本 | 小ワーク |
| 77-85分 | お金の話：採用単価の比較（求人媒体費 vs 求人票改善）＋研修助成金の触り（第1講ほど深くしない） | 共通クロージング素材を流用 |
| 85-90分 | まとめ＋個別相談案内（LINE）「今日の求人票、御社の実物で仕上げるのは個別相談で」 | 共通導線 |

**専用プロンプト（配布資料に追加する3本）**
- P8 求人票の辛口診断：「あなたは28歳の転職希望者です。以下の求人票を読んで、応募したくない理由を遠慮なく5つ挙げてください。そのあと、どこをどう直せば応募したくなるかを教えてください。【求人票を貼る】」
- P9 求人票の書き直し（逆質問法）：「あなたは中小企業専門の採用コンサルタントです。私は求人票を作り直したい。いきなり書かず、仕事内容・待遇・職場の実際・来てほしい人物像を私に1つずつ質問してください。全部そろったら、その1人に刺さる求人票を書いてください。」
- P10 面接質問シート：「あなたは採用面接の専門家です。◯◯職の面接で使う質問を10個作ってください。見極めたいのは△△です。あわせて、法律上・マナー上聞いてはいけない質問の例と、代わりの聞き方も教えてください。」

**注意点（第1講レビューの教訓を継承）**
- 求人票の実物を貼る際は社名を伏せる（会場ルール共通）
- 面接NG質問の解説は「一般的な情報提供」に留め、個別の労務判断は社労士へ（線引きの型を流用）
- デモの競合求人は架空の文面を事前作成（実在他社の求人を晒さない——地元で刺される）
- 効果は「応募数」で測る：講座の1か月後にLINEで「応募来ましたか？」と聞く仕掛け＝フォローアップ兼営業接点

**制作するもの（第1講の型を流用）**：スライド約15枚／講義原稿／配布資料（プロンプトP8-P10追加ページ＋面接質問シート雛形＋求人票ビフォーアフター例）／デモ用の架空競合求人2本

## 第4部：第3講以降の量産の回し方

1. **1講あたりの制作は「設計1日→スライド・原稿1日→配布資料半日」**。共通部品（導入5分・ルール・逆質問法・クロージング・助成金触り）は使い回すため、新規制作は本編ワーク3本と魅せデモだけ
2. 制作順は固定しない。**直前の講のテーマ投票1位を次に作る**（需要駆動）。ただし第4講（技術承継）は投票に関係なく早めに作る——川崎での指名され度が最も高く、業界特化サービス（事業化）への種になるため
3. 各講の動画版も同じ型で量産 → チャンネルが「悩み別の連載」になり、検索流入の面が増える
4. 6講たまった時点で「6回コース（各90分×6=9時間+個別1時間=10時間超）」に再パッケージ可能——**つまりシリーズがそのまま助成金対象の企業研修商品になる**。ここがシリーズ化の最大の伏線
